# Module 1: Semantic HTML and Forms

## Goals
- Understand the core ideas of Semantic HTML and Forms.
- Run and modify the examples.
- Complete the practice tasks independently.

## Practice
1. Reproduce each example from memory.
2. Change at least two inputs and observe the result.
3. Add one feature of your own.
4. Write a short note describing what you learned.

## Challenge
Build a small feature that combines the concepts from this module.
