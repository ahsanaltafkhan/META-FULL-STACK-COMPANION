# Meta Full-Stack Developer — Original Companion Repository

This repository is an **original study companion** for the Meta Full Stack Developer Specialization on Coursera.

It covers the same broad learning path with original explanations, examples, exercises, mini-projects, and practice prompts.

## Courses

1. Introduction to Front-End Development
2. Programming with JavaScript
3. Version Control
4. HTML and CSS in Depth
5. React Basics
6. Advanced React
7. Programming in Python
8. Introduction to Databases for Back-End Development
9. Django Web Framework
10. APIs

## Important

This repository does **not** contain copied Coursera/Meta lectures, readings, quizzes, graded-assignment answers, or proprietary course files. Use the official course for those materials and use this repository for independent practice.

## Stack

HTML, CSS, Bootstrap, JavaScript, Jest, Git, GitHub, React, Python, SQL, MySQL concepts, Django, REST APIs, JSON.

## Suggested workflow

For every module:
1. Read the module README.
2. Run every example.
3. Complete the exercises without looking at solutions.
4. Extend the mini-project.
5. Commit your work with Git.
